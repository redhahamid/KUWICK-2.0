# Kuwick HR & Payroll — design reference mockups

Static HTML mockups. Open any file in a browser. Names and amounts are fictional demo data.
Use these as the visual target for the HR module (layout, spacing, colours, cards, chips, buttons).
They are a design reference, not production code: rebuild them with the app's own components.

- Main.html — Payroll step 1 Prepare (grid)
- Review.html — Payroll step 2 Review (Needs action / For information / Done)
- Pay.html — Payroll step 4 Pay (payment listing + statutory filings)
- Payslip.html — one employee's month
- Staff.html — staff list
- StaffProfile.html — staff profile, Statutory tab
- SetupWizard.html — Settings while setup is incomplete
- SettingsHome.html — Settings after setup (4 cards + Advanced)
- Settings.html — older settings draft, superseded by SetupWizard + SettingsHome
